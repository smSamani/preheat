# Repository guide

- This repo is documented as an Open Knowledge Format v0.2 bundle in `docs/`. Start at `docs/index.md`.
- Any code change must update the matching concept file in `docs/` (`generated.at`, `status`, `stale_after`, content) and add an entry to `docs/log.md`.
- Results and figures are regenerated by `python -m preheat` and committed together with the code change that alters them.

Commands:

```
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m preheat
python -m preheat ask --offline
pytest -q
```
