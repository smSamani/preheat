# preheat

`preheat` is a small local Python tool about one synthetic heat-pump home on one synthetic winter day. It asks how much evening heat-pump electricity can be moved earlier by warming the house in advance, for two insulation levels, as the maximum indoor temperature varies. It is a personal curiosity project.
